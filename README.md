## 🌟 លក្ខណៈពិសេសសំខាន់ៗ (Key Features)

### ១. ផ្ទាំងទិដ្ឋភាពទូទៅ និងស្ថិតិ (Dashboard & Analytics)
- **កាតស្ថិតិស្វ័យប្រវត្តិ៖** បង្ហាញចំនួនសំណុំរឿងសរុប, ករណីទទួលពាក្យបណ្ដឹង, កំពុងស៊ើបអង្កេត, កំពុងដោះស្រាយ និងបិទបញ្ចប់។
- **ក្រាហ្វិកស្ថិតិ (Chart.js Integration)៖**
  - ក្រាហ្វិកបែងចែកតាមស្ថានភាពសំណុំរឿង (Doughnut Chart)
  - ក្រាហ្វិកបែងចែកតាមប្រភេទវិវាទ/បទល្មើស (Horizontal Bar Chart)
- **តារាងសកម្មភាពថ្មីៗ៖** បង្ហាញសំណុំរឿងចំនួន ៥ ដែលទើបធ្វើបច្ចុប្បន្នភាពចុងក្រោយគេ។

### ២. បញ្ជីសំណុំរឿង និងការច្រោះទិន្នន័យ (Case Directory & Filtering)
- **ឧបករណ៍ស្វែងរកឆ្លាតវៃ៖** ស្វែងរកតាមលេខសំណុំរឿង, ចំណងជើង, ឈ្មោះដើមបណ្ដឹង/ចុងបណ្ដឹង, ឬមន្ត្រីទទួលបន្ទុក។
- **ជម្រើសច្រោះទិន្នន័យ (Multi-Filter)៖** ច្រោះតាមស្ថានភាព, ប្រភេទវិវាទ (រដ្ឋប្បវេណី, ព្រហ្មទណ្ឌ, វិវាទដីធ្លី, វិវាទការងារ, រដ្ឋបាល, ពាណិជ្ជកម្ម) និងកម្រិតអាទិភាព (បន្ទាន់ខ្លាំង, ខ្ពស់, មធ្យម, ទាប)។
- **ការតម្រៀបទិន្នន័យ (Sorting)៖** តម្រៀបតាមកាលបរិច្ឆេទថ្មី/ចាស់, លេខសំណុំរឿង, ឬកម្រិតអាទិភាព។
- **ប្រព័ន្ធបែងចែកទំព័រ (Pagination)៖** បង្ហាញ ៨ សំណុំរឿងក្នុងមួយទំព័រ ងាយស្រួលពិនិត្យមើល។

### ៣. ការគ្រប់គ្រងទិន្នន័យសំណុំរឿង (CRUD Operations)
- **បង្កើតសំណុំរឿងថ្មី (Add Case)៖** ហ្វូមបញ្ចូលព័ត៌មានលម្អិត រួមមានលេខសំណុំរឿង, កាលបរិច្ឆេទ, ភាគីពាក់ព័ន្ធ, ទីតាំង, សេចក្ដីសង្ខេប និងចំណាត់ការបន្ត។
- **កែសម្រួលទិន្នន័យ (Edit Case)៖** អាចធ្វើបច្ចុប្បន្នភាពស្ថានភាព និងចំណាត់ការបានគ្រប់ពេលវេលា។
- **មើលប័ណ្ណព័ត៌មានលម្អិត (Dossier Modal)៖** បង្ហាញទិន្នន័យសំណុំរឿងនីមួយៗជាទម្រង់ប័ណ្ណឯកសារផ្លូវការ និងអាចប្តូរស្ថានភាពរហ័ស។
- **លុបទិន្នន័យ (Delete Case)៖** មានប្រព័ន្ធបញ្ជាក់សុវត្ថិភាពមុននឹងលុប។

### ៤. ម៉ាស៊ីនផលិតរបាយការណ៍ និងការទាញយក (Report Generation & Export)
- **ជម្រើសផលិតរបាយការណ៍ ៥ ប្រភេទ៖**
  1. របាយការណ៍សង្ខេបស្ថិតិទូទៅ
  2. របាយការណ៍បែងចែកតាមស្ថានភាពជាក់លាក់
  3. របាយការណ៍បែងចែកតាមប្រភេទ/បទល្មើស
  4. របាយការណ៍តាមដានការងារតាមមន្ត្រីទទួលបន្ទុក
  5. របាយការណ៍បញ្ជីសារពើភ័ណ្ឌសំណុំរឿងលម្អិត
- **ចម្រោះតាមកាលបរិច្ឆេទ៖** អាចកំណត់កាលបរិច្ឆេទ ចាប់ពីថ្ងៃណា ដល់ថ្ងៃណា។
- **ទម្រង់របាយការណ៍រដ្ឋបាលផ្លូវការ៖** ភ្ជាប់ជាមួយក្បាលកថា (ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ) និងកន្លែងចុះហត្ថលេខា។
- **ការបោះពុម្ព និង PDF (Print & Save PDF)៖** ប្រើប្រាស់ Print CSS សម្រាប់បោះពុម្ពលើក្រដាស A4 បានយ៉ាងស្អាត និងរៀបរយ។
- **ទាញយកជា Excel (.xlsx)៖** ភ្ជាប់ជាមួយបណ្ណាល័យ SheetJS សម្រាប់ទាញយកទិន្នន័យរបាយការណ៍ជាឯកសារ Excel សម្រាប់កែសម្រួលបន្ត។

### ៥. ការរក្សាទុកទិន្នន័យ និងប្រព័ន្ធបម្រុងទុក (Storage & Backup)
- **Offline-First Storage៖** ទិន្នន័យទាំងអស់ត្រូវបានរក្សាទុកដោយសុវត្ថិភាពក្នុង Browser LocalStorage មិនទាមទារអ៊ីនធឺណិត ឬ Server ឡើយ។
- **Export Backup (.json)៖** ទាញយកទិន្នន័យទាំងមូលក្នុងប្រព័ន្ធរក្សាទុកជាឯកសារ Backup សម្រាប់ការពារការបាត់បង់ ឬផ្ទេរទៅកុំព្យូទ័រផ្សេង។
- **Import Backup (.json)៖** ស្ដារទិន្នន័យពីឯកសារ Backup ចូលក្នុងប្រព័ន្ធវិញបានភ្លាមៗ។
- **Reset to Mock Data៖** អាចស្ដារទិន្នន័យមកទិន្នន័យគំរូដើម (១០ សំណុំរឿងខ្មែរ) វិញគ្រប់ពេលសម្រាប់ការសាកល្បង។

## 🎨 សោភ័ណភាព និងការរចនា (Design & UI/UX)
- **ពុម្ពអក្សរខ្មែរស្តង់ដារ Google Fonts៖** ប្រើប្រាស់ពុម្ពអក្សរ **"Kantumruy Pro"**, **"Battambang"**, និង **"Inter"** ធានាការអានងាយស្រួល និងស្រស់ស្អាត។
- **Dark Mode / Light Mode៖** អាចប្តូរពណ៌ផ្ទៃខាងក្រោយរវាងម៉ូដភ្លឺ និងម៉ូដងងឹត (Night Mode) បានយ៉ាងរលូន។
- **Modern Glassmorphism & Animations៖** ការរចនាកាតបែបទំនើប ជាមួយចលនាតូចៗ (Micro-animations) និង Toast Notifications។

## 🚀 របៀបប្រើប្រាស់ និងដំណើរការ (How to Run)

ដោយសារកម្មវិធីនេះត្រូវបានសរសេរដោយប្រើប្រាស់ **Core HTML5, Vanilla CSS3, និង JavaScript (ES6)** លោកអ្នកមិនចាំបាច់ដំឡើង ឬ Compile កូដស្មុគស្មាញឡើយ៖

1. **វិធីទី១ (បើកផ្ទាល់)៖** ចុចពីរដង (Double-click) លើឯកសារ `index.html` ដើម្បីបើកក្នុង Web Browser (Chrome, Edge, Safari, Firefox) ជាការស្រេច!
2. **វិធីទី២ ( Dev Server)៖** ប្រសិនបើលោកអ្នកប្រើប្រាស់ VS Code អាចចុច **Right-click លើ `index.html` -> Open with Live Server** ឬប្រើពាក្យបញ្ជាក្នុង Terminal:
   ```bash
   npx serve .
   ```

## 📁 រចនាសម្ព័ន្ធឯកសារគម្រោង (Project Structure)
```text
កម្មវិធីគ្រប់គ្រងសំណុំរឿង/
│
├── index.html         # ទំព័រមេនៃកម្មវិធី (Layout, Sidebar, Modals, Views)
├── README.md          # ឯកសារពន្យល់អំពីកម្មវិធី
│
├── css/
│   └── style.css      # រចនាប័ទ្មទាំងអស់ (Variables, Glassmorphism, Dark Mode, Print CSS)
│
└── js/
    ├── data.js        # គ្រប់គ្រង CRUD, LocalStorage, Mock Data, និង Backup/Restore
    ├── charts.js      # គ្រប់គ្រងក្រាហ្វិកស្ថិតិជាមួយ Chart.js
    ├── reports.js     # ម៉ាស៊ីនផលិតរបាយការណ៍ផ្លូវការ, បោះពុម្ព និងទាញយក Excel
    └── app.js         # គ្រប់គ្រង UI Events, Modal Toggles, ស្វែងរក និង Navigation
```
